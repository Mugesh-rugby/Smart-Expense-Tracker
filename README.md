# 💰 Smart Expense Tracker

Smart Expense Tracker is a desktop-based application developed using **Java**, **Java Swing**, **MySQL**, and **JDBC**. The application helps users manage their daily income and expenses efficiently with a simple and user-friendly interface.

---

# 🚀 Features

- User Login & Registration
- Add Income and Expenses
- Expense Categories Management
- View Transaction History
- Monthly Expense Summary
- Balance Calculation
- Edit & Delete Transactions
- Search and Filter Records
- Responsive Dashboard UI

---

# ⚙️ Installation

## 1. Clone the Repository

```bash
git clone https://github.com/Mugesh-rugby/Smart-Expense-Tracker.git
```

## 2. Open Project

Open the project using:
- IntelliJ IDEA
- Eclipse
- NetBeans

## 3. Setup MySQL Database

```sql
CREATE DATABASE expense_tracker;
```

Import the `database.sql` file into MySQL.

## 4. Configure JDBC

Update database username and password in the database connection file.

## 5. Run the Project

Compile and run the main Java file.
